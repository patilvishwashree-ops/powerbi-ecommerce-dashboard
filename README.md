# Power BI E-Commerce Dashboard

## 📊 Project Overview
This Power BI project analyzes e-commerce business performance, focusing on sales, profit, customers, and product trends to support data-driven decision-making.

## 🧰 Tools & Technologies
- Power BI Desktop
- DAX
- Data Modeling
- Data Visualization

## 📁 Dataset
The dataset contains e-commerce transaction data including:
- Orders
- Customers
- Products
- Sales & Profit
- Categories and regions

(*Data used for learning/portfolio purposes*)

## 📈 Key Insights
- Sales and profit trends over time
- Top-performing products and categories
- Customer purchasing behavior
- Regional performance comparison


## 🚀 How to Use This Project
1. Download the `Ecommrece.pbix` file
2. Open it using **Power BI Desktop**
3. Explore dashboards and insights

## 📌 Notes
- Data is anonymized and used only for educational purposes
- Live Power BI Service link available upon request
